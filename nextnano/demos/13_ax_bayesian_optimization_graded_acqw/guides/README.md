# Demo 13 guides

_Generated by `guides13.py` — edit that, not this file._

Demo 13 uses **Bayesian optimization** to search for an asymmetric coupled quantum well with the strongest second-order nonlinear response at 1550 nm, subject to physical quality constraints.

## How the search works

1. **Sobol phase** — a handful of quasi-random designs, to give the model something to learn from.
2. **Model-based (MBM) phase** — a Gaussian-process surrogate proposes each next design, balancing predicted strength against uncertainty.
3. **Preflight** — every proposal is checked *before* the solver runs. An unbuildable geometry is refused, costs no solver time, and does not consume a BO iteration.
4. **Evaluation** — nextnano++ solves the accepted design; the response and quality metrics are extracted and returned to the optimizer.

A proposal is therefore not the same thing as an evaluation, and this distinction runs through every guide here.

**Current result (experiment v3).** 23 proposals, 7 refused before the solver ran, 16 completed with no solver failures, **3 feasible**. The best feasible trial is **t0021** (asymmetry 0.387565, central barrier 0.85 nm, abrupt, relative chi2 at 1550 nm = 0.411027, detuning -13 nm). t0021 sits on the barrier **lower bound** and Stage 5 has not run, so it is the best design *found*, **not a validated optimum**.

**Units.** Every chi(2) number in this demo is a *relative* merit in arbitrary units (`a.u. (relative |chi2|)`). It is a lineshape and a trend with no absolute calibration. It is **never pm/V**, and values are only comparable between designs computed with the same mesh and settings.

## Vocabulary that is easy to mix up

| Term | Means |
|---|---|
| proposal | a design Ax suggested — it may never have been simulated |
| completed trial | a design the solver actually evaluated |
| refused / rejected proposal | refused at preflight; **no solver ran** |
| feasible trial | completed *and* satisfied every constraint |
| Sobol evaluation | one of the quasi-random initial designs |
| MBM iteration | one *completed* model-based evaluation, numbered 1-10 |
| proposed geometry | what the optimizer asked for |
| realized geometry | what the deck actually built — the only physical one |
| observed | measured by the solver |
| surrogate prediction | the model's belief, not a measurement |
