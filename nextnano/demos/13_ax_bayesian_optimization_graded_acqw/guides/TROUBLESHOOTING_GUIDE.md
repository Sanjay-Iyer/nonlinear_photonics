# Demo 13 troubleshooting guide

_Generated by `guides13.py` — edit that, not this file._

Symptom, cause, and what to do.

---

## `analysis mode found no Ax snapshot in ...`

**Cause.** `workflow.experiment_state_dir` names a directory that does not exist.

**Do this.** The error lists the directories that DO hold a snapshot. Set the setting to the one you meant. Analysis mode deliberately refuses to create an empty experiment, because it would then be reported as if it were the real campaign.

## `cannot resume this experiment: the Ax search space has changed`

**Cause.** A setting that defines the search space differs from the one the snapshot was written with.

**Do this.** The message names the exact field and both values. Either restore the configuration, or point `experiment_state_dir` at a NEW directory. The old one is never modified.

## Reanalysis prints `Generated new trial`

**Cause.** The run is not in analysis mode.

**Do this.** Stop it. Set `workflow.mode: analyze_existing_results`. In analysis mode the experiment is opened read-only and generation raises.

## Reanalysis prints `Executing ... case.in`

**Cause.** The run is not in analysis mode, and it is spending licensed solver time.

**Do this.** Stop immediately and check `workflow.mode`.

## `refusing to ...: this experiment was opened read-only for analysis`

**Cause.** Something tried to mutate a protected experiment during analysis.

**Do this.** This is the guard working correctly. Report it — analysis should never attempt a write.

## Surrogate plots are placeholders

**Cause.** No predictive model could be reconstructed.

**Do this.** Read `extracted/analysis_model_reconstruction.json`; `fit_status_reason` says why. This is a MODEL problem, never a missing-solver problem.

## Surrogate surfaces look sparse or patchy

**Cause.** Usually correct behaviour, not a bug.

**Do this.** Grid points whose realized grade would fall below 0.80 nm are withheld from the graded branch, because their physical structure is abrupt. Each withheld row carries the reason in the CSV.

## `bo_candidate_rejection_history.csv` is empty

**Cause.** Historically: it was built from in-memory loop state that reanalysis never has.

**Do this.** It is now rebuilt from the ledger. An empty table means the ledger has no rejected records — check the ledger directly.

## Run status says `failed` but nothing failed

**Cause.** Refused proposals were being counted as solver cases.

**Do this.** Fixed: refusals are excluded from the case list. On a machine with no solver the status is `dry_run_complete`, which is correct.

## `optimization_completed` is false after a finished campaign

**Cause.** It used to read a key the planner never returned.

**Do this.** It now reads the authoritative accounting. Check `extracted/campaign_accounting.json`.

## Refused proposals described as duplicates

**Cause.** The lifecycle text was hardcoded.

**Do this.** Fixed. A refusal is only a duplicate when its reason says so; v3 had **zero** duplicates and seven sub-resolution refusals.

## BO iteration numbers run past the configured budget

**Cause.** The ledger's `iteration` column counts proposal ATTEMPTS.

**Do this.** Use `mbm_iteration_number` from `bo_trial_iteration_mapping.csv`, which runs 1-10 over completed model-based evaluations.

## Reading the wrong report bundle

**Cause.** Bundles are timestamped and never overwritten.

**Do this.** Sort by name and take the last: bundle names are UTC timestamps.

## Composition / alloy-profile figures are empty

**Cause.** The transferred bundle contains no raw solver output.

**Do this.** Run `bundle_raw_trials.py` on the work laptop. Until then, no claim about a realized grading profile has evidence behind it.

## Stage 5 writing into the v3 experiment directory

**Cause.** Stage 5 must not share a directory with the protected campaign.

**Do this.** Set `validation_study.output_state_dir` to a separate directory. The configuration is rejected at startup if it points at the optimization experiment.

## Git tree is dirty before a licensed run

**Cause.** The results could not be attributed to a commit.

**Do this.** Commit or stash first. v3 was run from a dirty tree and its provenance is correspondingly weaker.
