# Demo 13 input parameters guide

_Generated by `guides13.py` — edit that, not this file._

Everything you can change, what it does, and whether changing it makes an existing optimization checkpoint unusable.

**Checkpoint invalidation.** Some settings define *what the search space is*. Changing one means the stored trials describe a different problem, so Demo 13 refuses to resume and tells you to start a new experiment directory. That refusal is a safety feature.

## Historical corrections and state identity

The protected v3 ledger is never rewritten. It preserves the values originally
stored in `stored_*` columns, while every current table, ranking, and plot uses
the matching `corrected_*` value recomputed from peak/target wavelengths or the
heavy-hole energy array. If primary data are absent, the corrected value is
`unavailable`, never zero; `derived_value_status` and
`derived_value_provenance` say exactly what happened.

State energies carry one of four provenance labels: `solver`, `parsed historical output`,
`synthetic test`, or `unavailable`. Synthetic index energies are
permitted only by an explicit test opt-in and are never scientific evidence.
Stage 5 assigns every case directly to `state_tracking.anchor_case`, so shuffling
case order cannot change its reference. Near a crossing or avoided crossing,
energy order can swap while the physical envelope continues smoothly; labels
therefore follow overlap (with real energy continuity only as a secondary cost),
and a small assignment margin is reported as ambiguous rather than smoothed
away.

**The geometry rule that surprises people.** The widest grade a design can build is `central barrier thickness - minimum_flat_region_nm`. With a 0.10 nm flat region and a 0.80 nm minimum resolvable grade, an **abrupt** design may use the full 0.85 nm barrier, but a **genuinely graded** design needs a barrier of at least **0.90 nm**. Between 0.85 and 0.90 nm the graded branch is empty and such proposals are refused.

## `bo.search_space.asymmetry_s`

**How unequal the two wells are. 0.5 would be symmetric; lower means a wider left well.**

- **Type:** BO parameter
- **Units:** dimensionless
- **Raising it:** shifts the resonance and changes which states overlap
- **Lowering it:** same axis, opposite direction; very low values give a near-zero response
- **Interacts with:** sets the peak wavelength together with the barrier, so it drives the detuning constraint
- **Invalidates an existing checkpoint:** yes

## `bo.search_space.central_barrier_thickness_nm`

**Thickness of the AlGaAs barrier between the two wells.**

- **Type:** BO parameter
- **Units:** nm
- **Raising it:** weakens tunnel coupling; states localize in one well
- **Lowering it:** strengthens coupling and generally raises the response, which is why the optimizer pushes to the lower bound
- **Interacts with:** CAPS the grading: max grade = barrier - minimum_flat_region_nm. Abrupt designs may use 0.85 nm, but a genuine 0.80 nm grade needs a barrier of at least 0.90 nm
- **Invalidates an existing checkpoint:** yes

## `bo.search_space.encoding`

**How the abrupt/graded choice is expressed to Ax. 'hierarchical' gives abrupt designs no grading parameters at all.**

- **Type:** BO parameter
- **Units:** category
- **Raising it:** n/a
- **Lowering it:** n/a
- **Interacts with:** hierarchical prevents one abrupt structure being proposed under five different profile labels
- **Invalidates an existing checkpoint:** yes

## `bo.search_space.grading_profile`

**Shape of the composition ramp across a graded interface.**

- **Type:** BO parameter
- **Units:** category
- **Raising it:** n/a
- **Lowering it:** n/a
- **Interacts with:** only 'linear' renders natively; the rest use a 16-sublayer staircase, which is why the grade mesh must be fine
- **Invalidates an existing checkpoint:** yes

## `bo.search_space.grading_fraction_of_feasible_max`

**What fraction of the available room to grade. Dimensionless, not nm.**

- **Type:** BO parameter
- **Units:** dimensionless
- **Raising it:** wider realized grade
- **Lowering it:** narrower, and below the resolvable minimum the proposal is refused
- **Interacts with:** the realized width is this times maximum_feasible_grading_nm, then snapped to the mesh
- **Invalidates an existing checkpoint:** yes

## `bo.search_space.minimum_mesh_resolvable_nonzero_grading_nm`

**The narrowest grade this mesh and profile implementation can build.**

- **Type:** geometry gate
- **Units:** nm
- **Raising it:** more graded proposals refused
- **Lowering it:** risks accepting a grade the grid cannot represent
- **Interacts with:** derived from the mesh and staircase_sublayers; must not sit below minimum_graded_thickness_nm
- **Invalidates an existing checkpoint:** yes

## `bo.search_space.minimum_graded_thickness_nm`

**At or below this width a design is treated as abrupt.**

- **Type:** geometry gate
- **Units:** nm
- **Raising it:** more designs collapse to abrupt
- **Lowering it:** risks calling a sub-mesh step a graded interface
- **Interacts with:** must be at least the resolvable minimum; validated at startup
- **Invalidates an existing checkpoint:** yes

## `bo.search_space.reject_subresolution_grades`

**Refuse a too-narrow graded proposal instead of silently making it abrupt.**

- **Type:** geometry gate
- **Units:** boolean
- **Raising it:** n/a
- **Lowering it:** n/a
- **Interacts with:** with it off, a 'sigmoid' trial with no grade enters the surrogate's training data -- the v2 defect
- **Invalidates an existing checkpoint:** no

## `bo.search_space.grading_fraction_spans_feasible_interval`

**Map the fraction onto [minimum, maximum] instead of [0, maximum], so every value builds a resolvable grade.**

- **Type:** BO parameter

## `numerical.active_region_grid_spacing_nm`

**Mesh spacing through the wells and barriers.**

- **Type:** fixed simulation setting
- **Units:** nm
- **Raising it:** faster, less resolved
- **Lowering it:** slower, better resolved; v3 uses 0.05 nm so a 0.85 nm barrier spans 17 cells
- **Interacts with:** two campaigns at different meshes are NOT comparable and cannot warm-start each other
- **Invalidates an existing checkpoint:** yes

## `grading.minimum_grid_points_per_grade`

**How finely the mesh is refined INSIDE a graded region.**

- **Type:** fixed simulation setting
- **Units:** count
- **Raising it:** better-resolved ramp, slightly slower
- **Lowering it:** risks a staircase finer than the grid that samples it
- **Interacts with:** must give at least one grid spacing per staircase sublayer; v3 uses 32 points so each of 16 sublayers is sampled twice
- **Invalidates an existing checkpoint:** no

- **Interacts with:** sets max feasible grade = central barrier - this value
- **Invalidates an existing checkpoint:** no
