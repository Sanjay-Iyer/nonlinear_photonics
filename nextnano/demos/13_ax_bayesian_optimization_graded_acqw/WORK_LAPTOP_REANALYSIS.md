# Work-laptop reanalysis of experiment v2 — exact commands and checklist

Regenerates every report from the completed 16-trial licensed study **without
calling nextnano once**.

This file is hand-maintained. `WORK_LAPTOP_RUN_GUIDE.md` is generated by
`report13.py` and will pick up the new configuration on the next run.

---

## 0. Before anything: confirm the experiment directory name

The committed `demo.yaml` now specifies:

```yaml
workflow:
  mode: analyze_existing_results
  experiment_state_dir: demo13_ax_experiment_v2
```

**This name was taken from the hardening brief and has not been verified against
the work laptop**, because `nextnano/results/demo_runs/**` is gitignored and the
completed experiment has never been in git. The home laptop has no copy of it.

If the directory is named something else, the run will **stop with an error that
lists the directories that do hold a snapshot** — it will not silently create an
empty study. Set `experiment_state_dir` to the name it prints and rerun.

```powershell
Get-ChildItem .\nextnano\results\demo_runs\13_ax_bayesian_optimization_graded_acqw\ -Directory | Select-Object Name
```

## 3. Confirm the pinned Ax version

```powershell
python -c "import ax, botorch, torch; print(ax.__version__, botorch.__version__, torch.__version__)"
```

Expect Ax `1.3.1`. The reconstruction is written against 1.3.1's
`GenerationNode._fit` and `Client.load_from_json_file`; a different major
version needs re-verification, not just a passing run.

running anything else.

## Expected behaviour

| Expectation | How to confirm |
|---|---|
| Zero solver calls | `Select-String -Path <bundle>\console.log -Pattern "Executing"` returns **nothing** |
| Zero new proposals | `Select-String -Path <bundle>\console.log -Pattern "Generated new trial"` returns **nothing** |
| 16 completed trials reloaded | `completed trials : 16` in the console summary |
| Predictive model reconstructed | `analysis surrogate : refitted_current_generation_node (TorchAdapter; 16 observations)` |
| Experiment untouched | `experiment state : unchanged after reanalysis` |
| Exit code zero | `$LASTEXITCODE` is `0` |

The run must **not** print `WARNING: reanalysis changed the protected experiment
state`. If it does, `extracted/experiment_state_protection.json` names what
changed; treat it as a bug and do not use the outputs.


### `plots/`

The five surrogate surfaces, three partial-dependence curves and the importance
bar chart must be **real figures, not placeholders**. A placeholder PNG is
under about 9 kB. If any is a placeholder, open the matching CSV: the `reason`
column says why, and it will name the model or the search space — never a
missing solver.

### `tables/` and root

`validation_report.md` must state licensed execution passed, 16/16 trials
completed, and Stage 5 pending. It must **not** say `implemented_dry_run` and
must **not** say no licensed solver ran.

## If anything fails

Do not rerun in `closed_loop`. Reanalysis cannot damage the experiment, but
`closed_loop` will spend licensed solver time continuing the study. Capture
`console.log`, `extracted/analysis_model_reconstruction.json` and
`extracted/experiment_state_protection.json` and bring them back to the home
laptop.
