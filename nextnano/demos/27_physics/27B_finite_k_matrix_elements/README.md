## Pass condition

O_nm(k), z_e,nl(k) and z_hh,ml(k) are reconstructed at every computed k, and M(k)/M(0) is reported for P1, Z1 (~605 nm), P2, P3, Z2 (~1330 nm) and P4. The sub-demo PASSES when that ratio exists and is quantified; it does not require the ratio to be large. A finding that M(k) is flat to 5% is a real answer and retires hypothesis 5 in the Demo 26 ranking.

## What it settles

Whether the frozen numerator M(k) = M(0) that every chi2 calculation in this
project has used is adequate. Demo 26 ranks this hypothesis 5 of 15 — "can alter
cancellations", medium confidence, unresolved.

The deliverable is M(k)/M(0) for each Equation 2 pathway — P1, Z1 (~605 nm), P2,
P3, Z2 (~1330 nm), P4 — from real finite-k data. **A finding that M(k) is flat to
5% is a real result** and retires the hypothesis. This sub-demo does not need the
ratio to be large in order to pass.

## Spinor conventions this commits to

An 8-band k.p state is a spinor, so inner products and position matrix elements
are summed over all eight components:

```
<a|b>   = sum_c integral conj(a_c(z)) b_c(z) dz
<a|z|b> = sum_c integral conj(a_c(z)) z b_c(z) dz
```

Equation 2 is written in one-band envelope language. The bridge is that the kp8
electron-like states are CB-dominated and the hole-like states HH-dominated, so
the Equation 2 quantities are the full spinor products for the physically
corresponding states. That is a **modelling choice, not an identity**, so the CB
and HH purity of every state is reported next to every matrix element.

State identity follows character, not energy order: Demo 24 found Demo 23's
`hh2` was 97.6% light-hole, precisely because an ordering rule cannot tell HH
from LH.

## Sizing

Demo 25 sizes the production grid from the 27A pilot's measured seconds-per-k and
bytes-per-k against explicit hour and gigabyte budgets, and recommends a smaller
matrix-element grid if 301 points would exceed them. That is sound physics as
well as sound engineering: the energies set the resonance positions and need fine
sampling, while the matrix elements vary slowly with k, so a coarser M(k) grid
interpolated onto the fine energy grid loses very little. The interpolation
refuses to extrapolate beyond the computed k range.

## Data harvest

Whenever this sub-demo's decks are solved, the shared broad harvest in `demo27_config.yaml` is requested — eigenenergies, envelopes, kp8 spinors, CB/HH/LH/SO character, probabilities, transition energies, dipole and momentum matrix elements, oscillator strengths, band edges, alloy composition, k vectors, dispersions and masses, plus electrostatic potential and strain where the deck already computes them.

No expensive new physics is enabled merely because an output would be interesting. The harvest costs disk, not solver time.
