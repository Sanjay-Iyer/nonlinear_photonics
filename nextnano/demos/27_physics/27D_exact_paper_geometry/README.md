# Demo 27D — Exact paper geometry - abrupt interfaces versus 1 nm grading

> **One question:** Does the paper's abrupt-interface structure reproduce the spectrum better than our 1 nm graded structure?

## Run it

```bash
python nextnano/demos/27_physics/run_demo27.py --demo 27D --preflight
```

```bash
python nextnano/demos/27_physics/run_demo27.py --demo 27D --physics --yes

python nextnano/demos/27_physics/run_demo27.py --demo 27D --record PASS --conclusion "..."
```

`--preflight` needs no license and runs anywhere. `--physics` refuses to start against a Free build, refuses without `--yes`, and refuses while a prerequisite is unmet. `--analyze` never launches a solver.

## Pass condition

The abrupt structure is solved with everything else held at the Demo 23 baseline, and the six Equation 2 features (P1 540, Z1 605, P2 760, P3 1080, Z2 1330, P4 1520 nm) are located in the normalized |chi2| for both structures and compared against the digitized paper curve. PASS means the comparison is made and the answer is stated either way. A result showing grading is NOT the explanation is a pass, and demotes hypothesis 1 in the Demo 26 ranking.

## The controlled change

The interface model, and nothing else. Layer widths, Al fractions, mesh, temperature, state count, k range and k sampling are the Demo 23 baseline, so the only thing that can move a spectral feature is the interface abruptness. The geometry is NOT optimized here; 27D asks whether the paper's structure explains the disagreement, not which structure fits best.

Fields this sub-demo may change: `interface_model`.
At most **1** per deck. Everything else is inherited verbatim from the Demo 23 baseline, and `framework/registry.resolve` raises rather than generating a deck that breaks either rule.

| Deck | Changed fields | Question |
|---|---|---|
| `abrupt_paper_geometry` | `interface_model` | Does the ideal abrupt structure move P1/Z1/P2/P3/Z2/P4 towards the paper? |

## The one change

`interface_model: linear_graded` → `abrupt`. Nothing else. Layer widths, Al
fractions, mesh, temperature, state count, k range and k sampling are the Demo 23
baseline, so the only thing that can move a spectral feature is the interface
abruptness.

## Why only one deck

The graded arm already exists. `demo_results/demo23/raw/production_y_n301_k0100`
is this exact structure with this exact solver configuration — 1 nm linear
grading at all four interfaces, 301 k points to 0.1 π/a, 14 states. Rerunning it
would buy nothing. See `REUSE_AUDIT.md`, which fingerprints it so the comparison
cannot silently be made against a different version.

## This is not an optimization

27D answers one question: **does structure mismatch explain a major portion of
the spectral disagreement?** It does not search for the geometry that best fits
the paper curve. Demos 12-14 did optimization; that is a different activity with
a different failure mode, and mixing the two would make a good fit
uninterpretable.

## What the paper actually specifies

Demo 26's `PAPER_STRUCTURE_REPRODUCTION_AUDIT.md` is the source for what "the
paper's structure" means here, and Demo 22's primary deck was already the ideal
abrupt geometry. Demo 26 ranks geometry mismatch **1 of 15**, medium-high
confidence, with "YES" against the unexplained P1/P3 group.

## How it is scored

The six features are located in the normalized |chi2| for both structures and
compared against Demo 26's `EXTENDED_FEATURE_DIAGNOSIS.csv` targets: P1 540,
Z1 605, P2 760, P3 1080, Z2 1330, P4 1520 nm. Demo 24's measured dLambda/dE per
feature converts any state-energy shift into a predicted wavelength shift, so the
prediction and the measurement can be checked against each other.

Note that the digitized paper curve is **diagnostic only**. Demo 23's
`PAPER_DATA_PROVENANCE.md` states it is eye-digitized and is not an acceptance
gate.

## Data harvest

Whenever this sub-demo's decks are solved, the shared broad harvest in `demo27_config.yaml` is requested — eigenenergies, envelopes, kp8 spinors, CB/HH/LH/SO character, probabilities, transition energies, dipole and momentum matrix elements, oscillator strengths, band edges, alloy composition, k vectors, dispersions and masses, plus electrostatic potential and strain where the deck already computes them.

No expensive new physics is enabled merely because an output would be interesting. The harvest costs disk, not solver time.
