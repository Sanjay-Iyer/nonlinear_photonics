# 28D — source of the imaginary component

Run `python scripts/run_response_audit.py` from the Demo 28 directory. See
`../../RESPONSE_AUDIT.md` for the methods, controls, results and limitations.
Numerators are real in the current baseline; complex denominators introduce Im,
and electron/hole terms strongly cancel. This is not a nonlinear-absorption
measurement or a carrier-population dynamics calculation.

Configuration: `../../config/response_audit.json`.
Outputs: `../../outputs/28D_imaginary_source/`.
