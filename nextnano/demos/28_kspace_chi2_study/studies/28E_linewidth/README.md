# 28E — Gamma / linewidth sensitivity

Run `python scripts/run_response_audit.py` from the Demo 28 directory. See
`../../RESPONSE_AUDIT.md`. All seven Gamma values retain complex spectra. Fixed
actual-transition detuning masks quantify near/off resonance. Small Gamma is
not grid-converged, and the displayed lobe widths are not fitted lifetimes.

Configuration: `../../config/response_audit.json` (`gamma_meV`, selected values,
resonance windows and ratio floor).
Outputs: `../../outputs/28E_linewidth/`.
