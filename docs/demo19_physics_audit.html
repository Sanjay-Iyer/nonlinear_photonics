02Grading geometry

The single most important definition to get right in the meeting, because it is not the convention used in Demos 13 or 14.

The definition

Grading width = the full, start-to-end width of the complete 0 ↔ 0.55 composition transition, centred on the nominal abrupt interface. It is not a half width, not a 10–90 % width, and not a Gaussian σ.

So a 0.7 nm grade means: at 0.35 nm before the interface xAl is exactly 0.55, at 0.35 nm after it is exactly 0.00, and at the interface itself it is exactly 0.275.

Formally, a grade of width w at interface position zi occupies the closed interval [z_i − w/2, z_i + w/2]. Demo 14 by contrast used a 10–90 % width so that different profile families would describe comparable interfaces; Demo 19 deliberately uses the full width so that the region of modified material is identical across families and only the shape inside it differs.

03Grading math

Every profile is one shape function applied identically at each graded interface. Nothing else varies.

The common construction

Baseline (no grading): x_Al(z) = 0.55 in the three barriers x_Al(z) = 0.00 in [I1, I2] and [I3, I4] For each interface i with width w > 0, on [z_i − w/2, z_i + w/2]: u = clip( ( z − (z_i − w/2) ) / w , 0 , 1 ) ← this is the ONLY place w enters f(u) = shape function, f(0) = 0 exactly, f(1) = 1 exactly x_Al(z) = x_start + ( x_end − x_start ) · f(u) with (x_start, x_end) = (0.55, 0.00) at I1 and I3 (x_start, x_end) = (0.00, 0.55) at I2 and I4

How xAl is normalised to span exactly 0 → 0.55: the shape function is normalised first, to run from 0 to 1 over u, and the composition endpoints are then applied as a plain affine map. Because f(0)=0 and f(1)=1 hold exactly (not asymptotically), the alloy fraction hits 0.000000 and 0.550000 exactly at the interval edges. No clipping is needed and none is applied to the composition itself; the only clip in the chain is on u outside the interval.

Say this precisely

“Fermi-like” and “erf” are endpoint-normalised truncated functions, not the bare logistic or error function. At a fixed 0.7 nm full width the three smooth families have quite different internal sharpness — the 10–90 % widths are 0.31 nm (fermi), 0.60 nm (erf) and 0.51 nm (cosine) against 0.56 nm for linear. Cases 10–12 therefore compare shape at fixed envelope, not sharpness at fixed sharpness.

Sampling of the imported profiles

For fermi/erf/cosine the analytic xAl(z) is sampled onto a table before nextnano sees it: uniform 0.05 nm spacing over the whole 0 – 30 nm domain, 601 rows — exactly the active-region mesh spacing. The sampler additionally forces a point at each zi and each zi ± w/2; because every width in the study is a multiple of 0.1 nm, those points already sit on the 0.05 nm lattice and the table stays uniform. verified

04nextnano representation

Two rendering paths. Only ternary_linear is native; nextnano++ 3.0.0 has no Fermi, erf or cosine grading keyword, so those go in as a data table. ternary_pyramid is never emitted and the preflight refuses any deck containing it.

Path A — abrupt and linear (native)

The whole domain is Al0.55Ga0.45As; the wells are carved out of it; the ramps are then written on top. nextnano++ applies later regions over earlier ones, so a ramp that overhangs a well region wins in the overlap — that ordering is deliberate and load-bearing.

ternary_linear semantics. alloy_x = [a, b] gives the Al mole fraction at the first and second spatial coordinate; x = [z0, z1] gives those coordinates in nm. Between them nextnano++ interpolates the alloy fraction linearly:

x_Al(z) = a + (b − a)·(z − z0)/(z1 − z0) for z0 ≤ z ≤ z1

The two x entries are positions, not compositions — a genuine trip hazard, since alloy_x and x sit side by side. I confirmed the semantics by running a probe deck through nextnano++ with a 0.55 → 0.00 ramp over [4.65, 5.35] and reading back alloy_composition.dat: the solver returned 0.373214285714 at z = 4.875 nm, which is 0.55 × (5.35 − 4.875)/0.7 to twelve digits. verified

Path B — fermi, erf, cosine (imported table)

The database carries no mass bowing for AlGaAs, so the mass is a straight linear interpolation of the mass parameter itself. To be certain it is not a harmonic (inverse-mass) average, I rebuilt the abrupt case in an independent BenDaniel–Duke solver: linear mass interpolation reproduces the solver's E1 and E2 to 0.06 and 0.07 meV, while inverse-mass interpolation is off by 2.1 and 7.7 meV. verified

Everything above is a local function of position

Because xAl varies with z through a graded interface, so do Ec(z), Ev(z) and m*(z) — continuously, on the same mesh. That is the entire physical content of this study: grading is not a boundary condition, it is a smooth spatial variation of the Hamiltonian's coefficients.

What is deliberately absent

StrainNot included. No strain{} block, no run{strain{}}. Confirmed in the output: the LH and HH edges are exactly degenerate in both materials, which cannot happen under biaxial strain. GaAs/AlAs mismatch is 0.14 %.
NonparabolicityNot included, and not available — nextnano++ 3.0.0's keyword grammar has no nonparabolicity option for the one-band Γ model. The dispersion is strictly parabolic.
Dielectric responseThe static and optical permittivities exist in the database but never enter: no Poisson equation is solved, and the χ² model uses ε₀ alone — no background refractive index, no local-field correction.
Piezo / pyroelectricNot included; irrelevant for unstrained [100] zincblende.
ExcitonsNot modelled at any stage.

06Quantum model

nextnano++ solves two independent single-band effective-mass eigenvalue problems, once, with no self-consistency and no space charge.

The equations actually solved

ELECTRONS (Γ): [ − ħ²/2 · d/dz ( 1/m*_Γ(z) · d/dz ) + E_c(z) ] ψ_n^e(z) = E_n^e · ψ_n^e(z)
HEAVY HOLES (HH): [ + ħ²/2 · d/dz ( 1/m*_HH(z) · d/dz ) + E_v(z) ] ψ_m^hh(z) = E_m^hh · ψ_m^hh(z)

Both are written on nextnano's single electron-energy scale, which is why the hole operator carries the opposite sign: confinement pushes hole levels down in this convention, and nextnano lists HH states in order of decreasing energy — index order is confinement order, so HH1 is the most confined hole. An interband transition is then a plain subtraction, Een − Ehhm.

The mass sits inside the derivative — the BenDaniel–Duke form. At an abrupt interface this makes ψ and (1/m)dψ/dz the continuous quantities. Inside a graded interface there is no interface condition at all: m*(z) varies smoothly and the operator is simply a smooth second-order operator. verified by reproducing the solver's eigenvalues to < 0.1 meV with an independent BenDaniel–Duke discretisation.

Nothing in Demo 19's analysis path reads them. Every overlap and every z matrix element in the results table is recomputed in Python from the envelope amplitudes. One presentational note on the tables: the sign of any single eigenvector is arbitrary, so entries like O12 and zhh,12 flip sign between cases. Each χ² numerator is a product in which the sign of any one state cancels, so |χ²| is unaffected — and the origin-independence check (translate z by 100 nm, re-evaluate, compare) is the end-to-end guard on this whole class of issue.

Why there is no ħ² in the prefactor. The published equation carries 1/(6ε₀ħ²) and writes both denominators as angular frequencies. Here the denominators are written in energy, which cancels the ħ² exactly. Every fixed parameter

State count2 per bandmax_states_per_band = 2 — E1, E2, HH1, HH2. Six states are requested from the solver and four are used. The triple sum is 8 conduction + 8 valence = 16 terms. Raising this changes what is being computed and is treated as a separate experiment, never inferred from how many states the solver returned.
Transition energies—Een − Ehhm on nextnano's single electron scale, plus the in-plane kinetic term. For the abrupt case: E1−HH1 = 1.48943 eV, E1−HH2 = 1.52248, E2−HH1 = 1.59929, E2−HH2 = 1.63235 eV.
Overlap definition—∫ψen(z)ψhhm(z)dz by trapezoid on the solver's grid, each envelope first renormalised so ∫ψ²dz = 1. Real-valued.
z element definition—∫ψi(z)·z·ψj(z)dz in nm, within one band only. Diagonal elements are individually origin-dependent; the dependence cancels between the two terms of the equation provided each band's envelopes are orthonormal, which is enforced at 10⁻³ and separately tested by shifting z by 100 nm.

Γ5.0 meVAdded as +iΓ to both denominators. Purely phenomenological — no temperature, carrier density or interface-roughness dependence, and identical in all 13 cases so it cannot masquerade as a grading effect.

Reading the abrupt spectrum

Four two-photon resonances fall inside the 1400–1800 nm window for the abrupt case — 1519.0 nm (E2→HH2), 1550.7 nm (E2→HH1), 1629.0 nm (E1→HH2) and 1664.9 nm (E1→HH1). The reported peak at 1517 nm is the E2→HH2 two-photon resonance, displaced slightly by the 5 meV broadening and by interference between the conduction and valence terms. The 1550 nm operating point sits essentially on the E2→HH1 two-photon resonance. All one-photon resonances lie near 760–830 nm, outside the window.

10The causal chain

This is the version to say out loud.

  1. Grading input → xAl(z)

    We pick one interface width and one shape family. The width defines a symmetric interval around each nominal interface, and the shape function maps position inside that interval onto a normalised 0-to-1 ramp. Multiplying by 0.55 gives a single-valued aluminium mole fraction at every point in the 30 nm device.

  2. xAl(z) → local material parameters and band edges

    nextnano++ evaluates the AlGaAs alloy formula pointwise: each parameter is interpolated between GaAs and AlAs at 300 K, with a composition-dependent bowing on the Γ gap. That turns the composition profile into three continuous spatial functions — the conduction band edge, the heavy-hole band edge, and the effective mass of each band. A graded interface is a smooth ramp in all three, not a step.

  3. Band edges and masses → quantum Hamiltonian

    Those functions are exactly the coefficients of the one-band effective-mass Hamiltonian: the band edge is the potential and the local mass sits inside the kinetic operator. There is no doping, no field and no space charge, so the potential the electrons see is the conduction band edge and nothing else. Grading is therefore a change to the Hamiltonian itself, not a boundary condition on it.

  4. Hamiltonian → electron and heavy-hole eigenstates

    The solver diagonalises the electron and hole problems independently on a 0.05 nm mesh with hard walls 2 nm outside the active region, returning six energies and six envelope functions per band. Softening an interface lowers the effective barrier the states see near that interface, so the levels shift and — more importantly for this study — the wavefunctions redistribute between the two wells.

  5. Eigenstates → energies, overlaps and dipoles

    From the first two states of each band we form the interband transition energies by subtraction, the electron–hole overlaps as envelope integrals, and the intra-band position matrix elements. The overlaps set how strongly each transition couples; the position elements set the asymmetry, which is the quantity that must be non-zero for any second-order response to exist at all.

  6. Matrix elements → χ² spectrum

    Those four numbers per state pair go into the interband second-order susceptibility as a sixteen-term sum of products, each divided by a one-photon and a two-photon complex denominator, integrated over in-plane momentum to a tenth of the Brillouin zone and scaled by two external constants — the unit-cell interband dipole and the well density. The output is a complex χ² in pm/V across 1400–1800 nm.

  7. Spectrum → the comparison we actually claim

    Every optical convention is frozen across the thirteen cases, and so is every numerical setting, so the only thing that differs between two spectra is the shape of xAl(z) at four named interfaces. The defensible claim is the ratio to the abrupt reference. Absolute agreement with an experiment is outside what this comparison is designed to establish.

11Twenty questions

The ones a semiconductor or quantum-well specialist is most likely to put to you, answered from the actual configuration.

01

Why one-band effective mass rather than 6- or 8-band k·p?

The deck requests Gamma{num_ev=6} and HH{num_ev=6}, which is nextnano++'s decoupled single-band model — no k·p block appears anywhere. The consequences are specific: no HH/LH mixing, no valence band warping, and no in-plane hole dispersion from the band structure at all, so the optical step imposes its own parabolic in-plane HH mass. This is the largest structural approximation in the model and it should be named before someone else names it. It is defensible for a Γ-point interband SHG estimate at a fixed structure, and it is applied identically to all thirteen cases.

02

What conduction/valence band offset ratio did you assume?

None — it is an output, not an input. The database carries absolute valence band offsets (GaAs 1.346 eV, AlAs 0.857 eV) plus the spin–orbit splittings, and the lineup follows from Ev(HH) = offset + ΔSO/3 and Ec = Ev + EgΓ. At x = 0.55 that gives ΔEc = 442.3 meV and ΔEv = 280.1 meV, i.e. 61.2 / 38.8. No Qc parameter appears in any configuration file.

03

Which bowing parameters, and is the temperature applied before or after alloying?

Composition-dependent Vurgaftman Γ bowing, C(x) = −0.127 + 1.310x, giving 0.5935 eV at x = 0.55 and a bowing correction of 0.147 eV. X bowing is 0.055 eV; L and ΔSO bowing are zero; there is no bowing on mass or band offset. Varshni is applied to each binary first, and the 300 K values are then interpolated. I verified that ordering: it reproduces the solver's Al0.55 gap of 2.1448956 eV exactly, while the other ordering differs by 0.06 meV.

04

Is the barrier effective mass interpolated in m or in 1/m?

Linearly in m, giving 0.11265 m₀ for the Γ electron and 0.50450 m₀ for the heavy hole at x = 0.55. The database has no mass bowing for AlGaAs. I confirmed this rather than assuming it: an independent BenDaniel–Duke reconstruction of the abrupt case reproduces nextnano's E1 and E2 to 0.06 and 0.07 meV with linear mass interpolation, and misses by 2.1 and 7.7 meV with harmonic (inverse-mass) interpolation.

05

Is strain included?

No. There is no strain{} block and no run{strain{}}, and the output confirms it — the light-hole and heavy-hole band edges come out exactly degenerate in both materials, which cannot happen under biaxial strain. The GaAs/AlAs lattice mismatch is 0.14 %, so a pseudomorphic calculation would shift HH and LH apart by a few meV and would not change the picture qualitatively, but this is a real omission and worth stating plainly.

06

Is conduction-band nonparabolicity included?

No, and it is not available: nextnano++ 3.0.0's keyword grammar has no nonparabolicity option for the one-band Γ model. The dispersion is strictly parabolic. E1 sits 55.8 meV above the GaAs Γ edge in the abrupt case, so a nonparabolic correction would be modest but not zero — and again, identical across all thirteen cases.

07

Is this Schrödinger–Poisson, and why is there a contact if there is no field?

Schrödinger only. The run statement is run{ quantum{} }, the quantum region carries no_density = yes, there is no doping and no bias. The zero-bias Fermi contact exists purely because nextnano++'s parser requires at least one; no Poisson equation is solved with it, so φ(z) ≡ 0 and the potential is exactly the material band edge. I verified this by reproducing E1 and E2 with a flat-band solver to under 0.1 meV, which would be impossible if any electrostatic potential were present.

08

Where are the quantum boundaries, and can the Dirichlet walls contaminate the states?

The walls sit at 7.1 and 22.9 nm — 2.0 nm outside the active region, leaving 7.1 nm of outer barrier beyond each wall. Every state's boundary probability is computed against a 10⁻³ threshold and recorded per state on the licensed machine. Because the box is identical in all thirteen cases, any residual wall effect is common-mode and largely divides out of the ratios to the abrupt reference.

09

Is a 0.05 nm mesh enough to resolve a 0.2 nm grade?

It gives four mesh intervals across the narrowest grade, fourteen at 0.7 nm and twenty-eight at 1.4 nm. The imported tables are sampled at exactly the same 0.05 nm, so the mesh and the table never disagree. What we have not run is a mesh-refinement study — the spacing is a fixed inherited value, identical across all cases, so it is controlled but not converged. That distinction is worth conceding directly if asked.

10

Does grading change the well widths or the period?

No. The nominal interface positions and the 30.0 nm total length are frozen; the grade replaces w/2 of material on each side of an interface. What does change is the amount of pure material: at 0.7 nm the thick well retains 6.4 nm of pure GaAs and the tunnel barrier 1.1 nm of full-composition AlGaAs. The composition at each nominal interface is always exactly half, 0.275.

11

Is "Fermi grading" a nextnano feature?

No — and the distinction is deliberate in the code. nextnano++ 3.0.0 has no ternary_fermi, ternary_erf or ternary_cosine keyword. Only linear grading is native, via ternary_linear. The three smooth families are Python-generated xAl(z) tables handed to the solver through import{} plus ternary_import{}, and every artifact labels them as such. ternary_pyramid is never emitted and the preflight rejects any deck containing it.

12

Are the imported cases really comparable to the native ones, given they use a different material keyword?

Yes. In the imported cases the wells are Al(x = 0)Ga(1−x)As rather than the literal binary GaAs entry, but the ternary formula at x = 0 returns the GaAs parameters exactly. I ran both through the solver: band edges 2.8821488095238 and 1.4596666666667 eV in both, identical to thirteen digits. The comparison between case 03 and case 10 is a comparison of profile shape, not of rendering path.

13

How much error does the imported table introduce?

Maximum deviation in Al fraction from the analytic profile is 3.3 × 10⁻³ for fermi, 1.6 × 10⁻³ for erf and 1.7 × 10⁻³ for cosine, against a 5 × 10⁻³ gate; linear and abrupt are exact because they are native syntax. Fermi is worst because its truncation leaves the steepest kink at the interval edges. There is a second, independent check after each solve: nextnano's own realised alloy_composition.dat is compared to the intended profile under the same tolerance, so a rendering failure would stop the case rather than propagate.

14

Only two states per band — is the sum converged?

It is a reproduction choice, not a convergence result, and the code is explicit about the difference. Six states are requested from the solver and exactly two per band enter the sum, fixing it at sixteen terms. Widening the sum changes what is being computed and would be a separate, deliberate experiment; the state counts at every layer — requested, returned, supplied, used, discarded — are recorded per case so this can never be quietly assumed.

15

Why is the heavy-hole mass 0.51 in one place and 0.112 in another?

Different directions. 0.51 m₀ is the growth-direction HH mass from the database and sets confinement in the Schrödinger equation. 0.112 m₀ is the in-plane HH mass and appears only in the parabolic k∥ dispersion of the transition energy in the optical step. Heavy holes really are light in-plane, so both numbers are physically right — but they come from two different models bolted together, and the in-plane value is a stated assumption rather than an output of the band-structure calculation.

16

What sets the absolute pm/V scale, and is anything fitted?

Nothing is fitted — there is no scale factor anywhere in the absolute path. Two external constants set the magnitude: re,hh = 0.751 nm from an HSE06 calculation in Ramesh et al. (2023), and Nz = 1/30 nm. The source paper does not publish both jointly, and the Nz counting convention is genuinely ambiguous, so both the alternative well-counting convention and the alternative Brillouin-zone-edge convention are computed and reported as sensitivities rather than chosen to match a published number.

17

Where does temperature enter the optical calculation?

It does not. The Fermi factor is unity throughout — valence band full, conduction band empty — with no thermal occupation and no Fermi level in the susceptibility step. The only place 300 K enters the entire chain is the Varshni band gaps inside nextnano. Broadening is a fixed phenomenological 5 meV added to both denominators, with no temperature, density or roughness dependence; it is identical across all thirteen cases, so it cannot masquerade as a grading effect.

18

Is there a refractive index or local-field correction in the χ²?

No. The prefactor carries ε₀ alone — no background dielectric constant, no Lorentz local-field factor, no cavity or metasurface enhancement. The database permittivities are never used because no Poisson equation is solved. What comes out is a bare material susceptibility for the multiple-quantum-well stack, and any device-level enhancement would sit on top of it.

19

Why does the abrupt spectrum peak at 1517 nm, and why report 1550?

The peak is the two-photon resonance of the E2→HH2 transition: 1.63235 eV gives 2hc/E = 1519.0 nm, displaced by the 5 meV broadening and by interference between the conduction and valence terms. 1550 nm is the inherited telecom operating point, and it happens to sit essentially on the E2→HH1 two-photon resonance at 1550.7 nm. Both the on-resonance peak and the fixed 1550 nm value are reported, which is why they move differently as grading widens.

20

Why does every row of the results table say physical_valid = False?

Because of a reporting-key defect, not a physics failure. All thirteen solves completed with return code 0 and produced complete output. The aggregate flag is read from a dictionary key named passed that the analysis routine never writes, so the flag evaluates false unconditionally for every case in this path. The individual physics checks — envelope orthonormality, origin independence, energy ordering, boundary probability, state-window consistency — are all computed and stored per case; they are simply never rolled up into that one field. Two knock-on effects to expect: the ratio-to-abrupt columns are blank in the master table, and the summary document rendered its pre-physics "pending" text even though the physics ran. See the flags below.

!!Open flags and unknowns

Things to say before someone finds them.

1 · physical_valid is false on all thirteen rows

All thirteen solves returned code 0 with complete output, and the χ² numbers in the table are real. The aggregate validity flag is read from a dictionary key that the analysis routine never writes, so it is unconditionally false for every case in this path. Two consequences visible in the artifacts: the chi2_1550_relative_to_abrupt and peak_chi2_relative_to_abrupt columns are empty, and the generated summary document rendered its pre-physics "pending" text. The per-case physics checks were all computed and stored; only the roll-up is broken.

2 · Material parameters read from the co-versioned free database

The licensed solves used database.nnp from the 2026_07_03 package on the work laptop, which is not present in this checkout. Every database value quoted here was read from database_free.nnp of the same 2026_07_03 package, and every band edge quoted was produced by running that same free build. The GaAs and AlGaAs entries are expected to be identical between the two files — the Free edition limits problem size, not database content — but that equality has not been checked directly.

3 · Two genuine unknowns

Eigenvalue solver. The deck sets no solver{}, accuracy or iterations, so nextnano++'s default applies; which algorithm that is cannot be established from the repository.

Total grid point count. The control lines are exact, but nextnano++ chooses the graded-spacing point count internally and that number is not in the artifacts copied off the licensed machine.

4 · Controlled, not converged

The 0.05 nm mesh, the 96-point k grid, the two-state truncation and the 5 meV broadening are all fixed inherited values applied identically to every case. That makes the comparison between cases clean, but none of them has been the subject of a refinement study within Demo 19. If asked whether a result is converged, the honest answer is that it is controlled.

5 · Native optical outputs go unused

nextnano++ computes overlaps, transition energies and growth-direction dipoles natively because the deck asks for them, and Demo 19 reads none of them — every such quantity in the results is recomputed in Python from the envelopes. A comparison routine between the two sources exists in the shared code but has only ever been used by another demo. Running it once for Demo 19 would turn a reasonable assumption into a verified one.
